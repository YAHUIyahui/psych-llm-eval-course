期末作业

题目：LLM 裁判评价 CBT 取向心理支持回复的效度，以及一个有评测的 CBT 支持 Agent

提交时间：第 28 天。占总成绩：60%。

1. 为什么做这个题目

心理健康聊天机器人的研究越来越多，但评价方法很不统一。Hua 等人（2025）的范围综述发现，多数研究使用临时编制、未经标准化的评价量表。大厂发布的基准（例如 OpenAI 的 MentalHealthBench）依赖自动评分裁判，但公开材料里很少报告裁判与临床专家的一致性。

这份作业要你做一项小型但完整的研究：把 LLM 裁判当作一个测量工具，用咨询师评分作为参照，检验它的信度、效度和偏差；同时搭建一个 CBT 支持 Agent，并用这套经过检验的方法评测它。

它和你的博士研究直接衔接：你做过 CBT 聊天机器人的随机对照试验，也做过面向老年人的数字心理健康研究。完成后，它可以成为面试时的核心项目；经过导师同意并补足伦理程序后，也可以发展成一篇方法学论文。

2. 研究问题

必做：

  • RQ1 信度：咨询师之间的一致性如何？同一 LLM 裁判重复评分的一致性如何？
  • RQ2 效标效度：LLM 裁判与咨询师评分的一致性如何？在不同维度、不同人群（老年人与大学生）、不同风险等级上是否不同？
  • RQ3 偏差：裁判是否存在位置偏差、长度偏差或自我偏好？
  • RQ4 Agent：你的 CBT 支持 Agent 与基线系统（单轮、无工具）相比，在安全门槛和各维度上是否不同？在风险题上重复运行时是否每次都正确（pass^k)?

选做（加分，最多 5 分）：

  • RQ5 题目分析：哪些情景的区分度最高？是否有题目应当修改或删除？

3. 数据与材料

  • 题目：data/prompts.csv(30 条）和 data/older_adult_vignettes.csv(12 条），共 42 条。可以增加题目，但要写明增加的理由和来源。所有题目必须是你编写的，不得使用真实来访者文字。
  • 系统：至少两个。推荐“基线”（同一模型，单轮回复，无工具）与“你的 Agent”（第 16 到 18 天搭建）。
  • 评分者：至少 2 位有咨询训练的评分者，对全部回复盲评（看不到系统来源，顺序打乱）。先做 5 条校准。
  • LLM 裁判：至少 1 个，固定版本与提示词，温度设为 0，每条回复评 3 次；成对比较时两种顺序都评。
  • 评分标准：docs/rubric.md（第 1 周的版本）。可以修改，但修改必须在看到正式数据之前完成，并记录理由。

没有 API 时：可以用课程的离线模拟流程完成全部分析，但报告中必须明确写“模拟数据”，且 RQ4 的结论只能是方法演示。

4. 交付物

  1. GitHub 仓库，结构如下，别人可以一条命令复现全部结果：
your-repo/
  README.md            研究摘要、如何运行、结果概览、局限
  docs/
    rubric.md
    analysis_plan.md   第 19 天之前提交(先于评分数据)
    decision_rule.md   第 4 天写的决策规则
    power.md           第 5 天写的功效说明
  data/                题目与评分(去标识)
  src/                 代码
  results/             表格与图,带 run manifest
  run_all.py           一条命令复现
  1. 研究报告：正文不超过 6 页（不含参考文献和附录），按论文格式：引言（研究空白与问题）、方法（题目、系统、评分者、裁判、分析计划）、结果（每个估计都带 95% 区间）、讨论（结果意味着什么、局限、下一步）。
  2. 10 分钟汇报幻灯片（约 10 页），用于面试时讲项目。
  3. 简历条目（3 行以内）和一段 2 分钟项目介绍录音。

报告和幻灯片的模板见 coursework/report_template.md 与 coursework/talk_outline.md。

8. 伦理与数据

  • 不使用任何真实来访者或研究参与者的文字。
  • 评分者以同事身份协助评分；记录资质（执业年限、是否受过 CBT 训练），仓库中不出现姓名。
  • 若要把结果投稿发表，请先与导师确认是否需要伦理审批，以及评分者是否需要签署知情同意。
  • API 密钥只放在环境变量里，不写进代码或 notebook。

9. 发展成研究的方向（选读）

  • 按人群分层的效度：LLM 裁判对老年人场景的评价是否与咨询师一致性更低？
  • 中文与英文情景的对比。
  • 把回复层面的质量评分与你的 RCT 结局数据联系起来（需要新的伦理批准）。
  • 投稿时可以考虑数字心理健康或医学信息学方向的期刊，例如 JMIR Mental Health、JMIR AI、npj Mental Health Research。具体选刊请和导师讨论。
