为什么从测量开始

评测结论被用来决定模型能不能上线，但给出结论的测量工具本身很少被检验。心理测量学处理同一个问题已经一百多年。

  • 被测对象一：来访者。PHQ-9 这样的量表，你最熟悉。
  • 被测对象二：聊天机器人的回复。由咨询师或 LLM 裁判按 rubric 打分。
  • 被测对象三：模型本身。让模型回答人格或心理量表，把它当作被试。
  • 三类问题用的是同一套概念：信度、效度、测量误差。

经典测量理论

X = T + E观测分 = 真分 + 误差
reliability = Var(T) / Var(X)真分方差占观测分方差的比例
  • 假设误差均值为 0，且与真分无关。
  • 两次平行测量的相关系数等于信度。
  • 信度是某个人群中分数的性质，不是工具单独的属性。换一个人群（比如从大学生换到老年人），信度要重新估计。

效度：测到的是想测的东西吗

  • 内容效度：题目是否覆盖了要测的范围，例如测试集是否覆盖老年人常见的求助场景。
  • 结构效度：分数的内部结构是否符合理论，例如共情维度是否与技术维度分开。
  • 效标效度：与外部标准的关系。同时效度看与专家评分的相关，预测效度看能否预测用户结局。
  • 后果效度：使用这些分数做决策会带来什么后果。
概念

现代测量理论（Messick, 1989；美国教育与心理测验标准， 2014）把效度看作对“分数如何解释和使用”的论证，不是工具本身的属性。

例一：让 LLM 填人格量表

Serapio-García 等人（2023, arXiv:2307.00184）把人格测验用于大模型，检验测得的人格分数是否可靠、有效。

  • 在特定提示设置下，部分模型的人格分数显示出信度和效度。
  • 较大的、经过指令微调的模型证据更强。
  • 模型输出的人格可以被定向塑造。
注意

模型对量表的回答随提示词变化，题目顺序、措辞都会改变分数。把人类量表直接用在模型上，需要先检验这些量表在模型上的测量性质。
