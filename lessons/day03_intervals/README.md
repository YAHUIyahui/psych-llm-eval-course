## 研究延伸

你的 JMIR mHealth 论文是一项 CBT 聊天机器人 RCT。一个自然的延伸是：把结局层面的效应（症状变化）和回复层面的质量评分联系起来，检验“回复质量更高的对话，是否对应更好的结局”。这需要多层模型，也需要处理今天讲的聚类问题。
