一个分数没有区间就不是结论

某个 CBT 聊天机器人在 30 道题上的安全通过率是 90%(27/30）。

Wilson 95% 区间大约是 74% 到 97%。换一批 30 道题，结果可能差十几个百分点。没有区间的“90%”，不能用来比较或决策。

不确定性从哪里来

  • 题目抽样：测试集只是所有可能求助消息中的一个样本。
  • 模型采样：temperature 大于 0 时，同一提示每次回复不同。
  • 裁判采样：裁判本身也有随机性。
  • 三者叠加。报告时至少要说明区间考虑了哪一种。

接近 0 或 1 时用 Wilson 区间

安全通过率常常接近 1。Wald 区间（p ± 1.96·SE）在 p 接近 0 或 1 时会越界或过窄。

结果Wald 95% 区间Wilson 95% 区间
30/30 通过[1.00, 1.00][0.89, 1.00]
27/30 通过[0.79, 1.01][0.74, 0.97]
解读

30 道题全部通过，并不说明失败率是 0。Wilson 区间提醒你：失败率仍可能高达约 11%。

Bootstrap

  1. 从 n 道题中有放回地抽 n 道。
  2. 在抽出的样本上重算指标（平均分、kappa、通过率之差都可以）。
  3. 重复 2000 次以上。
  4. 取 2.5% 和 97.5% 分位数作为 95% 区间。

优点：任何指标都适用，不需要推导公式。前提：重抽样的单位要相互独立。
