3. 页面是否报告了自动评分裁判与临床专家的一致性？如果没有，你会怎么补？

## 研究延伸

很多心理健康 LLM 研究只用几十条对话就得出结论。一项有价值的方法学工作是：系统地报告已发表研究的 MDE，类似元分析中的功效审查。你做过三层元分析，这个方向很顺手。
