连续分数的题量公式

n ≈ ( (z₁₋α/₂ + z₁₋β) · s / δ )²s = 逐题差值的标准差，δ = 想检测的差

例：s = 0.8,δ = 0.2,α = 0.05，功效 0.8:n ≈ (2.80 × 0.8 / 0.2)² ≈ 126 道题。

不加题也能提高功效

  • 配对设计：两个系统做同一批题。
  • 重复采样：每题生成或评分多次取平均，降低噪声。
  • 降低裁判噪声：更清楚的 rubric，温度设为 0，多裁判平均。
  • 挑高信息量的题：第 6、8 天的 IRT 方法。
  • 聚焦主要指标：少做比较，减少多重校正的代价。
