## 今日论文

https://aclanthology.org/2021.acl-long.346

## 研究延伸

把 IRT 用在心理健康评测集上，可以回答“哪些临床情景最能区分模型”。例如：间接表达的风险、老年人特有的担忧，是否是高区分度的题？这需要足够多的模型或模型配置，可以通过同一模型的不同系统提示来扩充被试。
