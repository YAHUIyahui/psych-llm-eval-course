## 研究延伸

在心理支持场景里，咨询师的成对偏好和来访者（或模拟来访者）的成对偏好可能不同。MentalHealthBench 的用户研究也发现专家和用户重视的东西不同。比较这两类偏好得到的排名，本身就是一个效度问题。
