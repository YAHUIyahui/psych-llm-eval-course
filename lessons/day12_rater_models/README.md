## 研究延伸

McBain 等人（2025）的研究发现中间风险等级最难判断。可以用 Dawid-Skene 或多面 Rasch 模型分析咨询师对中间风险消息的分歧：是评分者差异，还是这些消息本身模糊？这对设计风险筛查评测集很有用。
