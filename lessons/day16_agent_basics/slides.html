什么是 Agent

Agent 是一个循环：模型决定要不要调用工具，程序执行工具，把结果交还给模型，直到模型给出最终回复。

心理支持 Agent 的工具可以是：记录情绪、安排行为激活活动、生成思维记录模板、提供危机资源。

工具设计原则

  • 名称和描述写清楚：模型靠描述决定什么时候用。
  • 参数少而明确，用 JSON Schema 约束类型和取值。
  • 返回结构化结果；出错时返回可读的错误，不要让循环崩溃。
  • 高风险动作（例如联系紧急联系人）需要人工确认。

真实部署的例子

Habicht 等人（2024, Nature Medicine）研究了英国 NHS 心理治疗服务中的自我转介聊天机器人 Limbic Access:28 家服务、4 万多名患者，使用聊天机器人的服务转介量增加约 15%，性别非二元和亚裔、非裔少数族群增加最多。

启示

这是一个“任务型”Agent：目标明确（完成转介），评估也围绕结局（转介量、等待时间）。
