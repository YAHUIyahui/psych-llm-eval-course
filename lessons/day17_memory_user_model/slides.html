确认特质：证据门槛

  1. 每次从对话中抽取一个候选特质（例如“偏好简短回复”）。
  2. 记录证据来源（哪次会话、哪句话）。
  3. 同一取值的证据达到门槛（例如 3 次）才确认。
  4. 只把已确认的特质放进提示词。

门槛越高，错误画像越少，但确认得越慢。

隐私与控制

  • 用户可以查看 Agent 记住了什么，并删除。
  • 用户可以关闭记忆。
  • 不记录不需要的敏感信息（诊断、用药），只记录对支持有用的偏好。
  • 日志和记忆分开存储，记忆要有来源和时间。
