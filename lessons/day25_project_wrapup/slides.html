README 的结构

  1. 一句话说明研究问题。
  2. 怎么运行（三行以内）。
  3. 主要结果：一张表，每个数字带区间。
  4. 一张图。
  5. 局限：具体到会影响哪个结论、往哪个方向偏。
  6. 数据与伦理说明。

怎样写局限

  • 泛泛：样本量较小。
  • 泛泛：未来研究可以扩大样本。
  • 具体：只有 3 位咨询师，α 的 95% 区间宽约 0.2，门槛判断在 D2 和 D5 上不稳定。
  • 具体：裁判与系统 B 同源，自我偏好估计可能与长度效应混在一起。
