# 参与者准备清单（第一次见面前完成）

- [ ] 安装 Python 3.10 或更高版本
- [ ] 下载或克隆课程仓库
- [ ] 在课程文件夹里运行：

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
pytest                             # 应显示全部通过
jupyter lab
```

- [ ] 打开 `lessons/day01_reliability_validity/notebook.ipynb`，从头运行到尾，没有报错
- [ ] 双击 `index.html`，能看到课程首页并打开第 1 天幻灯片
- [ ] 在 GitHub 新建一个自己的私有仓库，用来放每天的作业和期末项目
- [ ] （可选）准备一个模型 API 密钥，只放在环境变量里

遇到安装问题，把报错全文贴到讨论群，或在课程仓库开一个 “问题” issue。
